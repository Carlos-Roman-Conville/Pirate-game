# Pirate Ship: rules

Not a traditional game: there is no rule book to source. The game's rules are Rex's design, in `PIRATE.md` and
`minigames/FISHING.md` (and `STATS.md`, `DUTIES.md`). This file exists because the template expects it.

- **Never invent a rule or mechanic.** A case the design docs don't cover is a question for Rex in HANDOFF.md
  Blocked, not a decision a task makes.
- The casino games the den will use are played by their own repos' engines (as in High Roller); this repo never
  retypes their rules.
- The board kit's placeholder (three in a row, D1–D3) is not part of the game; no task adds D-rows.
