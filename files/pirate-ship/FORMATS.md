# Pirate Ship: modes and variants

How the game can be played here, and which rule variants are options at setup (`PsOptions`, each a D-row).

| Mode | How | Status |
|---|---|---|
| Against the computer | three levels (easy, medium, hard), either side | engine + screen |
| Two players, one screen | same device, turns alternate | engine + screen |
| Online match | through the lobby (contract v3, `?match=`), host seat 0, guest seat 1 | engine + screen |
| Spectate | a spectator token on a match | engine + screen |
